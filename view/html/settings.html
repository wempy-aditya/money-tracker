Belum diperiksa

Disimpan di database lokal. Tidak pernah dikirim kembali ke browser setelah disimpan.

Hanya mengubah cara bicara. Aturan inti asisten (tidak bisa membuat transaksi, tidak mengarang angka) tetap berlaku di semua gaya.

Pengaturan lanjutan

Makin rendah, makin konsisten dan tidak banyak menebak.

Yang perlu diketahui

  • Asisten hanya bisa membaca data. Tidak bisa membuat transaksi, memindahkan uang, atau mengubah anggaran.
  • Setiap pertanyaan dan jawaban tersimpan di database lokal dan ikut dibaca sebagai konteks pertanyaan berikutnya.
  • Isi profil dulu kalau mau sarannya lebih sesuai kondisi Anda.
  • Untuk layanan lokal tanpa API key, biarkan kolom key kosong.
